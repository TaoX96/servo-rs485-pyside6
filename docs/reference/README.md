# Reference files

Copy the original supplied files into this directory without editing them:

- `parameter lists of A6-RS series servo drive manual(1).pdf`
- `nonverbose_bestCode(1).py`
- `CamTemControlMonitorv3(1).py`
- `TechnikerSchule März2025_Gruppe 1 Dokumentation FINAL.pdf`
- `Tao_Xiong_Thesis.pdf`
- `Raspberry Pi Comprehensive Monitoring System.vi`

These files document the legacy system and are not imported or executed by the new
application. If Git repository size is a concern, store the large PDF/VI files outside Git
and keep their filenames, versions, checksums, and retrieval location here.
